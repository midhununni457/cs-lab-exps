1. FIND EPSILON-CLOSURE OF ALL STATES OF ANY GIVEN NFA WITH EPSILON TRANSITIONS
File: Eclosure_nfa.c

--- Main Algorithm ---
Step 1: Start.
Step 2: Read the total number of states 'n'.
Step 3: Read the n x n epsilon transition matrix 'e', where e[i][j] = 1 indicates 
        an epsilon transition from state i to state j, and 0 otherwise.
Step 4: For each state i from 0 to n - 1:
        a. Initialize a visited array 'vis' of size n with all 0s.
        b. Print "E-Closure(i): ".
        c. Call Procedure DFS(i).
        d. Print a newline.
Step 5: Stop.

--- Procedure DFS(s) ---
(Finds all states reachable from state s via epsilon transitions)
Input: State index 's'
Step 1: Mark state s as visited: vis[s] = 1.
Step 2: Print state s.
Step 3: For each state j from 0 to n - 1:
        If there is an epsilon transition from s to j (e[s][j] == 1) and state j 
        is not yet visited (vis[j] == 0):
            Recursively call Procedure DFS(j).
Step 4: Return.

2. CONVERT NFA WITH EPSILON TRANSITIONS TO NFA WITHOUT EPSILON TRANSITIONS
File: Enfa_to_nfa.c

--- Main Algorithm ---
Step 1: Start.
Step 2: Read the total number of states 'n'.
Step 3: Read the total number of input symbols 'num_sym'.
Step 4: Read the n x n epsilon transition matrix 'e', where e[i][j] = 1 indicates
        an epsilon transition from state i to state j, and 0 otherwise.
Step 5: For each input symbol s from 0 to num_sym - 1:
        Read the n x n transition matrix t[s] for symbol s.
Step 6: For each input symbol s from 0 to num_sym - 1:
        For each state i from 0 to n - 1:
          a. Initialize visited array 'vis' of size n with all 0s.
          b. Call Procedure CLOSURE(i, vis) to find all states reachable from state i 
             via epsilon transitions.
          c. For each state j that belongs to epsilon-closure(i) (vis[j] == 1):
             For each state k from 0 to n - 1:
               If there is a transition from j to k on symbol s (t[s][j][k] == 1):
                   Set transition c[s][i][k] = 1 in the new NFA.
Step 7: Display the resulting transition matrix c[s] for each input symbol s.
Step 8: Stop.

--- Procedure CLOSURE(s, vis) ---
(Computes the epsilon closure of state s and stores reachable states in array vis)
Input: State index 's', array 'vis'
Step 1: Mark state s as visited: vis[s] = 1.
Step 2: For each state j from 0 to n - 1:
        If there is an epsilon transition from s to j (e[s][j] == 1) and state j 
        is not yet visited (vis[j] == 0):
            Recursively call Procedure CLOSURE(j, vis).
Step 3: Return.

3. CONVERT NFA TO DFA (SUBSET CONSTRUCTION)
File: nfa_to_dfa.c

--- Main Algorithm ---
Step 1: Start.
Step 2: Read the number of NFA states 'n'.
Step 3: Read the number of input symbols 'num_sym'.
Step 4: For each input symbol s from 0 to num_sym - 1:
        Read the n x n transition matrix trans[i][s][k] for all states i and next states k.
Step 5: Represent each subset of NFA states using an integer bitmask, where bit i is 
        set to 1 if state qi is present in the subset.
Step 6: Initialize a FIFO queue to store DFA state subsets, and a 'visited' array with all 0s.
Step 7: Enqueue the initial DFA state {q0} represented by bitmask 1 (1 << 0):
        queue[rear++] = 1.
Step 8: While the queue is not empty (front < rear):
        a. Dequeue current subset: current = queue[front++].
        b. If visited[current] == 1, continue to next iteration.
        c. Mark visited[current] = 1.
        d. Print current subset identifier.
        e. For each input symbol j from 0 to num_sym - 1:
           i.   Initialize next subset bitmask: next = 0.
           ii.  For each state i in current subset (if current has bit i set):
                For each target state k from 0 to n - 1:
                  If trans[i][j][k] == 1, add state k to next subset (next |= (1 << k)).
           iii. Print transition: current on input j -> next.
           iv.  If state 'next' has not been visited (visited[next] == 0):
                Enqueue 'next' into the queue (queue[rear++] = next).
Step 9: Stop.

4. MINIMIZE ANY GIVEN DFA
File: dfa_minimize.c

--- Main Algorithm ---
Step 1: Start.
Step 2: Read the total number of states 'n'.
Step 3: Read the total number of input symbols 'num_sym'.
Step 4: For each input symbol s from 0 to num_sym - 1:
        Read the n x n transition matrix, where entry (i, k) is 1 if state i 
        transitions to state k on symbol s (setting trans[i][s] = k).
Step 5: Read the final state status for each state into array 'final' 
        (1 for final state, 0 for non-final state).
Step 6: For each state i from 0 to n - 2:
        For each state j from i + 1 to n - 1:
          Check if state i and state j are 1-equivalent:
          a. Check if both states have the same acceptance status: 
             final[i] == final[j].
          b. For each input symbol k from 0 to num_sym - 1:
             Check if transitions lead to states with identical acceptance status:
             final[trans[i][k]] == final[trans[j][k]].
          c. If condition holds for all input symbols:
             Print states qi and qj as equivalent states.
Step 7: Combine equivalent states into unified states to produce the minimized DFA.
Step 8: Stop.

5. DESIGN AND IMPLEMENT A LEXICAL ANALYZER IN C (IGNORING SPACES, TABS, NEWLINES)
File: lexer.c

--- Main Algorithm ---
Step 1: Start.
Step 2: Initialize a list of standard language keywords: 
        {"int", "float", "char", "if", "else", "while", "for", "return", 
         "void", "main", "printf", "scanf"}.
Step 3: Open the source code file ("input.txt") in read mode.
        If file pointer is NULL, display "Cannot open input.txt" and terminate.
Step 4: Read characters from the file one by one using ch = fgetc(fp) until EOF:
        a. If ch is a whitespace (' '), tab ('\t'), or newline ('\n'):
           Ignore and continue to the next character (filters redundant spaces).
        b. If ch is an alphabet (isalpha(ch)):
           i.   Initialize buffer index i = 0.
           ii.  While the next character is alphanumeric (isalnum(ch)):
                Append ch to buffer buf[i++] and read next character: ch = fgetc(fp).
           iii. Null-terminate buffer: buf[i] = '\0'.
           iv.  Push the extra non-alphanumeric character back to file stream 
                using ungetc(ch, fp).
           v.   Call Function isKeyword(buf):
                - If true: print "Keyword: buf".
                - If false: print "Identifier: buf".
        c. Else if ch is a digit (isdigit(ch)):
           i.   Initialize buffer index i = 0.
           ii.  While the next character is a digit (isdigit(ch)):
                Append ch to buffer buf[i++] and read next character: ch = fgetc(fp).
           iii. Null-terminate buffer: buf[i] = '\0'.
           iv.  Push the extra non-digit character back using ungetc(ch, fp).
           v.   Print "Number: buf".
        d. Else if ch is an arithmetic or relational operator (+, -, *, /, =, <, >):
           Print "Operator: ch".
        e. Else if ch is a punctuation symbol or delimiter ((, ), {, }, ;, ,):
           Print "Symbol: ch".
Step 5: Close the file stream using fclose(fp).
Step 6: Stop.

--- Function isKeyword(str) ---
Input: String 'str'
Output: Returns 1 if 'str' matches any keyword in the keyword list; otherwise returns 0.
Step 1: For each keyword kw[i] in the keyword list:
        If strcmp(str, kw[i]) == 0:
            Return 1.
Step 2: Return 0.

9. CONVERT BNF RULES INTO YACC FORM AND GENERATE ABSTRACT SYNTAX TREE (AST)
Folder: abs_syn_tree/ (ast.l, ast.y)

--- AST Node Data Structure ---
Define structure for syntax tree nodes:
struct node {
    char label[20];
    struct node *left;
    struct node *right;
};

--- Helper Procedures ---
Procedure mknode(char *label, node *l, node *r):
Input: Operator label string, left child pointer l, right child pointer r
Step 1: Allocate memory for a new node: n = malloc(sizeof(node)).
Step 2: Copy label into n->label.
Step 3: Set child pointers: n->left = l, n->right = r.
Step 4: Return node pointer n.

Procedure mkleaf(int val):
Input: Integer value
Step 1: Allocate memory for a leaf node: n = malloc(sizeof(node)).
Step 2: Format integer val into string and store in n->label.
Step 3: Set leaf child pointers: n->left = NULL, n->right = NULL.
Step 4: Return node pointer n.

Procedure print_tree(node *n, int depth):
Input: Node pointer n, integer depth (indentation level)
Step 1: If n is NULL, return.
Step 2: Print 2 * depth spaces for tree indentation.
Step 3: Print node label n->label followed by a newline.
Step 4: Recursively call print_tree(n->left, depth + 1).
Step 5: Recursively call print_tree(n->right, depth + 1).
Step 6: Return.

--- Lexical Analyzer Algorithm (ast.l) ---
Step 1: Include "y.tab.h".
Step 2: Rules:
        a. [0-9]+                 -> Set yylval.val = atoi(yytext); return NUM.
        b. [a-zA-Z][a-zA-Z0-9]*   -> Return token ID.
        c. [ \t]                  -> Ignore spaces and tabs.
        d. \n                     -> Return newline token '\n'.
        e. .                      -> Return character yytext[0].

--- Parser Algorithm (ast.y) ---
Step 1: Declare %union { struct node *nd; int val; } to hold tree pointers and values.
Step 2: Declare tokens %token <val> NUM ID and non-terminal types %type <nd> expr term factor.
Step 3: Specify precedence: %left '+' '-' and %left '*' '/'.
Step 4: Define grammar rules to build the AST bottom-up:
        Rule 1: stmt -> expr '\n'
                Action: Set root = $1, call print_tree(root, 0), return 0.
        Rule 2: expr -> expr '+' term   Action: $$ = mknode("+", $1, $3)
                     |  expr '-' term   Action: $$ = mknode("-", $1, $3)
                     |  term            Action: $$ = $1
        Rule 3: term -> term '*' factor Action: $$ = mknode("*", $1, $3)
                     |  term '/' factor Action: $$ = mknode("/", $1, $3)
                     |  factor          Action: $$ = $1
        Rule 4: factor -> '(' expr ')'  Action: $$ = $2
                       |  NUM           Action: $$ = mkleaf($1)
Step 5: Define error routine yyerror(char *s): Print "Error: %s\n".
Step 6: Define main(): Prompt with "Enter expression: " and invoke yyparse().
Step 7: Stop.

11. COMPUTATION OF FIRST AND FOLLOW SETS OF A CONTEXT-FREE GRAMMAR
File: first_follow.c

--- Main Algorithm ---
Step 1: Start.
Step 2: Read the total number of productions 'n'.
Step 3: Read each production rule string in the format "LHS=RHS" (using '#' for epsilon).
        Extract and store all unique LHS non-terminals in array 'nonterms'.
Step 4: Print "First Sets:".
Step 5: For each non-terminal A in 'nonterms':
        a. Initialize a boolean array 'res' of size 128 with all 0s.
        b. Call Procedure findFirst(A, res).
        c. Display "First(A) = { " followed by all characters j where res[j] == 1.
Step 6: Print "Follow Sets:".
Step 7: For each non-terminal A in 'nonterms':
        a. Initialize a boolean array 'res' of size 128 with all 0s.
        b. Call Procedure findFollow(A, res).
        c. Display "Follow(A) = { " followed by all characters j where res[j] == 1.
Step 8: Stop.

--- Procedure findFirst(c, res) ---
Input: Symbol 'c', result array 'res'
Step 1: If c is a terminal (not an uppercase letter):
        Set res[(int)c] = 1 and return.
Step 2: If non-terminal c is already marked as visited on the current recursion path:
        Return (guards against stack overflow on left-recursive grammars).
Step 3: Mark c as visited on the current recursion path: visited[c] = 1.
Step 4: For each production prods[i] where LHS == c:
        a. If RHS begins with '#' (epsilon):
           Set res['#'] = 1.
        b. Else, for each consecutive symbol prods[i][j] in the RHS starting at j = 1:
           i.   Initialize a temporary array 'temp' with 0s.
           ii.  Recursively call findFirst(prods[i][j], temp).
           iii. Add all non-epsilon symbols from 'temp' into 'res': res[k] |= temp[k] for k != '#'.
           iv.  If 'temp' does not contain epsilon ('#'), break out of the RHS scan.
           v.   If end of RHS is reached and all symbols derived epsilon, set res['#'] = 1.
Step 5: Reset visited[c] = 0 (unmark for other alternative search paths).
Step 6: Return.

--- Procedure findFollow(c, res) ---
Input: Non-terminal 'c', result array 'res'
Step 1: If c is not a valid non-terminal or already marked as visited in follow computation:
        Return.
Step 2: Mark c as visited: visited[c] = 1.
Step 3: If c is the start symbol (first non-terminal, index 0):
        Add end-marker '$' to res: res['$'] = 1.
Step 4: For each production prods[i]:
        Scan RHS for occurrences of symbol c at position j:
        a. While subsequent symbol prods[i][k] exists (where k starts at j + 1):
           i.   Compute First(prods[i][k], temp).
           ii.  Add all non-epsilon symbols from 'temp' to 'res'.
           iii. If 'temp' does not contain epsilon, set has_epsilon = 0 and break.
           iv.  Increment k.
        b. If all subsequent symbols derive epsilon (or c is the rightmost symbol) 
           and LHS != c:
           Recursively call findFollow(LHS, res).
Step 5: Return.

12. RECURSIVE DESCENT PARSER FOR AN ARITHMETIC EXPRESSION GRAMMAR
File: rec_desc_parser.c

Grammar:
    E  -> T E'
    E' -> + T E' | - T E' | #
    T  -> F T'
    T' -> * F T' | / F T' | #
    F  -> ( E ) | id

--- Main Algorithm ---
Step 1: Start.
Step 2: Read the input arithmetic expression string ending with '$'.
Step 3: Initialize input pointer pos = 0.
Step 4: Invoke the start symbol procedure E().
Step 5: Check lookahead symbol:
        If input[pos] == '$', print "Parsing successful!".
        Else, print "Parsing failed!".
Step 6: Stop.

--- Procedures ---
Procedure match(c):
    If input[pos] == c, increment pos++.
    Else, print error with expected symbol and terminate execution.

Procedure E():
    Print "E -> T E'".
    Call T().
    Call EP().

Procedure EP():
    If lookahead() == '+':
        Print "E' -> + T E'".
        match('+').
        Call T().
        Call EP().
    Else if lookahead() == '-':
        Print "E' -> - T E'".
        match('-').
        Call T().
        Call EP().
    Else:
        Print "E' -> #" (epsilon production).

Procedure T():
    Print "T -> F T'".
    Call F().
    Call TP().

Procedure TP():
    If lookahead() == '*':
        Print "T' -> * F T'".
        match('*').
        Call F().
        Call TP().
    Else if lookahead() == '/':
        Print "T' -> / F T'".
        match('/').
        Call F().
        Call TP().
    Else:
        Print "T' -> #" (epsilon production).

Procedure F():
    If lookahead() == '(':
        Print "F -> ( E )".
        match('(').
        Call E().
        match(')').
    Else if lookahead() is alphanumeric:
        Print matched token label.
        Advance pos++.
    Else:
        Print syntax error and terminate.

13. OPERATOR PRECEDENCE PARSER
File: op_prec_parser.c

--- Main Algorithm ---
Step 1: Start.
Step 2: Define terminal array: terminals = {'i', '+', '*', '(', ')', '$'}.
Step 3: Define 6 x 6 operator precedence table matrix with relations:
        '<' (yields precedence / shift), '>' (takes precedence / reduce),
        '=' (equal precedence), and ' ' (syntax error).
Step 4: Read input string ending with '$'.
Step 5: Push '$' onto the parser stack and initialize input pointer ip = 0.
Step 6: Display table headers: "Stack", "Input", "Action".
Step 7: Loop:
        a. Find the topmost terminal symbol 'a' on stack by scanning downward using 
           Procedure topTerminal() (ignoring non-terminals like 'E').
        b. Let 'b' be current lookahead symbol input[ip].
        c. Print current stack contents and remaining input string.
        d. If a == '$' and b == '$':
           Print "Accepted" and terminate loop.
        e. Look up relation table[idx(a)][idx(b)]:
           i.   If relation is '<' or '=':
                - Push incoming symbol 'b' onto stack.
                - Increment input pointer ip++.
                - Print "Shift b".
           ii.  If relation is '>':
                - Print "Reduce".
                - If top of stack is identifier 'i': pop 'i'.
                - Else if top of stack matches parenthesized handle "(E)":
                  pop ')', 'E', and '('.
                - Else if top of stack matches binary handle "E op E":
                  pop right 'E', operator op, and left 'E'.
                - Push non-terminal 'E' onto stack.
           iii. If relation is ' ' (empty) or symbol is invalid:
                - Print "Error" and terminate loop.
Step 8: Stop.

14. SHIFT REDUCE PARSER FOR A GIVEN GRAMMAR
File: shift_reduce.c

--- Main Algorithm ---
Step 1: Start.
Step 2: Read the total number of grammar rules 'ng'.
Step 3: Read grammar productions (e.g. E=E+E, E=E*E, E=i).
Step 4: Read number of input tokens 'ni', followed by token sequence ending with '$'.
Step 5: Push '$' onto parser stack. Initialize input pointer ip = 0.
Step 6: Extract the start symbol LHS (e.g. "E") from the first grammar rule.
Step 7: Display table headers: "Stack", "Input", "Action".
Step 8: Loop:
        a. Format and display current stack and remaining input.
        b. Check Acceptance:
           If stack has exactly 2 elements ("$" and start symbol) and current 
           input token is "$":
               Print "Accepted" and terminate loop.
        c. Try Reduce:
           For each grammar production rule g from 0 to ng - 1 (LHS = RHS):
               Check if top of stack matches RHS:
               If a match is found:
                   - Pop RHS length tokens from stack.
                   - Push LHS non-terminal onto stack.
                   - Print "Reduce LHS->RHS".
                   - Set reduced = 1 and break out of production check.
        d. Try Shift:
           If no reduction occurred (reduced == 0):
               - If input pointer is not at end token "$":
                   Print "Shift input[ip]".
                   Push input[ip] onto stack.
                   Increment ip++.
               - Else:
                   Print "Error" and terminate loop.
Step 9: Stop.

15. INTERMEDIATE CODE GENERATION (THREE ADDRESS CODE FOR ARITHMETIC EXPRESSIONS)
File: icg.c

Grammar:
    E -> E + T | E - T | T
    T -> T * F | T / F | F
    F -> ( E ) | id

--- Main Algorithm ---
Step 1: Start.
Step 2: Read arithmetic assignment expression string (e.g. "a=b+c*d").
Step 3: Extract LHS target variable identifier 'id', skip '=' sign, and set pos = 2.
Step 4: Print "Three Address Code:".
Step 5: Evaluate expression by calling Procedure E(), returning pointer to final result name.
Step 6: Print final statement: "id = result".
Step 7: Stop.

--- Procedures ---
Procedure newTemp():
    Format next temporary variable name "t%d" using incrementing counter 'temp'.
    Return pointer to allocated temporary string.

Procedure F():
    If lookahead() == '(':
        Advance pos++ (skip '(').
        Call E() to evaluate inner expression.
        Advance pos++ (skip ')').
        Return inner result pointer.
    Else:
        Allocate distinct buffer from results pool.
        Copy current identifier character into buffer.
        Advance pos++.
        Return buffer pointer.

Procedure T():
    Call F() to parse left-hand factor: left = F().
    While lookahead() == '*' or lookahead() == '/':
        Save operator: op = lookahead(), advance pos++.
        Call F() to parse right-hand factor: right = F().
        Allocate new temporary: t = newTemp().
        Print 3AC instruction: "t = left op right".
        Set left = t.
    Return left.

Procedure E():
    Call T() to parse left-hand term: left = T().
    While lookahead() == '+' or lookahead() == '-':
        Save operator: op = lookahead(), advance pos++.
        Call T() to parse right-hand term: right = T().
        Allocate new temporary: t = newTemp().
        Print 3AC instruction: "t = left op right".
        Set left = t.
    Return left.

16. TARGET CODE GENERATOR (8086 ASSEMBLY CODE GENERATION)
File: codegen.c

--- Main Algorithm ---
Step 1: Start.
Step 2: Read total number of three address code statements 'n'.
Step 3: Read and store all 'n' three address code statements into a string buffer array 
        (each line formatted as "result = arg1 op arg2" or assignment "result = arg1").
Step 4: Print header: "\n8086 Assembly Code:\n".
Step 5: For each statement i from 0 to n - 1:
        Parse statement tokens: result, arg1, op, arg2.
        a. If statement is a simple copy assignment (tokens == 2 or op == "="):
           Print "MOV result, arg1".
        b. Else if op == '+':
           Print "MOV AX, arg1".
           Print "ADD AX, arg2".
           Print "MOV result, AX".
        c. Else if op == '-':
           Print "MOV AX, arg1".
           Print "SUB AX, arg2".
           Print "MOV result, AX".
        d. Else if op == '*':
           Print "MOV AX, arg1".
           Print "MUL arg2".
           Print "MOV result, AX".
        e. Else if op == '/':
           Print "MOV AX, arg1".
           Print "DIV arg2".
           Print "MOV result, AX".
        f. Print empty line separator.
Step 6: Stop.
